### Self-hosted stdlib: pure-Ny fallbacks for C feature modules

Principle: **fallback-first, never a rewrite**. The C library stays the default complete route; the fallback is a bounded pure-Ny path (like the existing in-tree zlib and the PNG fallback already using it) that makes the module work without the C library, selected by an env toggle in the established `_png_disable_libpng_cache` style (`_<module>_disable_<lib>` cached env read), and both routes are covered by fixtures. Only what the existing module actually consumes is supported — anything else fails closed with a message naming the C-route requirement. Keep the scope simple; do not reimplement full libraries:

- [ ] `lib/math/parse/img/png.ny` (libpng, `extern "png16"` + `<png.h>`) — the fallback exists behind `NY_PNG_DISABLE_LIBPNG=1`; make it a first-class route: audit its gaps against the libpng route (color types, bit depths, interlacing, filter coverage), extend what the png fixtures actually need, add fixture runs for both routes (`NY_PNG_DISABLE_LIBPNG=1` and unset), and pin the env naming convention from this module for the others below.
- [ ] `lib/math/parse/img/jpeg.ny` (libturbojpeg, `extern "turbojpeg"`) — add a pure-Ny **baseline JPEG decode** fallback (DCT/Huffman baseline only): keep `turbojpeg` as the complete fast path; the fallback handles the baseline files the image fixtures use and fails closed on progressive/lossless with a message naming the turbojpeg route. No encoder.
- [ ] `lib/math/parse/img/webp.ny` (libwebp, `extern "webp"`) — add a pure-Ny fallback starting with **VP8L (lossless) decode** — the bounded subset; lossy VP8 stays libwebp-only and fails closed with a message naming the libwebp route until separately tracked. No encoder, no vp8.
- [ ] `lib/os/sound/res.ny` (libsndfile, `sf_`) — add a pure-Ny fallback for the load path covering **WAV with PCM/float sample formats** (i16/i24/i32/f32, the fixtures' formats), plus AU if trivially shared; every other container/format fails closed naming the sndfile route. Writing stays sndfile-only for now.
- [ ] `lib/math/crypto/analysis/dictionary.ny` (libcrypt, `<crypt.h>`, `crypt()`) — add a pure-Ny fallback implementing **only the crypt scheme(s) the module generates or verifies today** (discover them from the module first, then implement those; typically `$1$`/`$6$`-style hashes), in the same in-tree spirit as `core.math.crypto.hash`; other schemes fail closed naming the libcrypt route.
- [ ] `lib/os/net/curl.ny` (libcurl, `curl_`) — add a pure-Ny HTTP/1.1 fallback over the existing `core.os.net.socket` transport for **plaintext `http://`** (GET/POST, redirects, chunked transfer), mirroring the module's `curl_request*` API so callers keep one surface; **`https://` stays libcurl-only in this item** (TLS is explicitly out of scope here — do not invent a TLS stack inside it; if wanted, track it separately). Fail-closed message when https is requested without libcurl present.
- [ ] Cross-item acceptance: every module keeps a single public API (no fallback-specific exports), loads with `dlopen`-optional machinery from `core.os.ffi` where the C lib is optional at link time, and a fixture runs each fallback route cold (C lib absent/blocked) to prove the pure-Ny path is reachable, not just declared.
